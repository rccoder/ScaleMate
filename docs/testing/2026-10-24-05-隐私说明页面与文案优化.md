# 隐私说明页面与文案优化

> 2026-10-24。用户要求优化设置中的隐私说明，安装橙色测试版后反馈“看到了，感觉可以”，并要求整体提交推送。本记录随本轮餐食改动一起提交；尚未公开发布。

## 页面与内容

- 原生单段 `TextView` 改为 Compose 页面：标题栏返回、浅绿摘要、六组主题卡片，统一圆角、行距和系统栏安全区域。
- 与主界面共用 `scaleMateColorScheme`，读取相同深色／动态配色选项，不引入第二套主题。
- 中英文说明分为本机记录、蓝牙权限、Health Connect、AI 数据与密钥、应用更新、撤权和删除。移除旧整段字符串，避免两份内容并存。
- 对照现有代码说明 AI 发送的照片、人数、标签和描述；图片重新编码移除 EXIF 位置元数据，画面中的可见内容仍发送；密钥以 Android Keystore 加密保存，局域网 HTTP 的请求及密钥为明文。
- 补充更新／测速会访问 GitHub 或代理，服务方可见 IP 与请求路径；不将更新请求描述为上传健康记录。Health Connect 只描述当前写入能力，不宣称已读取 Google 健康全量数据或已在目标应用显示。
- 删除与撤权边界区分未来写入、已写入记录及其他应用副本，不承诺撤权即删除所有数据。
