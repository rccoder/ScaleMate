
`sha256sum -c SHA256SUMS`、包名 `app.scalemate`、版本名、versionCode、非调试属性与固定证书均通过 `check_release.py` 核验：

```sh
python3 scripts/check_release.py --tag v0.4.0-preview.2 \
  --apk /tmp/scalemate-v0.4.0-preview.2/ScaleMate.apk \
  --build-tools /home/rccoder/.local/share/health-connect-tools/sdk/build-tools/36.0.0
```

## 应用内升级

在 API 36 Google APIs 模拟器 `emulator-5556` 先确认已安装 `0.4.0-preview.1 / code 14`，保持预览通道执行“检查更新”。应用发现 `0.4.0-preview.2 / code 15`，展示更新摘要与已知问题，随后使用 GitHub 官方线路下载；下载完成后 Android 系统安装器显示覆盖更新确认，确认“更新”后安装成功并正常启动。

## 下载线路

实际附件测速中，GitHub 官方、`gh-proxy.com`、`ghfast.top` 和 `gh-proxy.org` 返回的 APK 大小与 SHA-256 均正确；`ghproxy.net` 本次 TLS 握手超时，`gh.llkk.cc` 返回 HTTP 522。失败线路没有被描述为可用，也不保证线路长期稳定。完整结果见 [source-report.json](2026-10-31-03-preview2-evidence/source-report.json)。

## 未覆盖边界

- 本轮只有模拟器，没有用户手机 ADB、真实相册和系统相机；没有在手机上完成相机取图、真实业务记录保留或真实 AI 服务验收。
- 本轮模拟器没有可用于迁移验收的非空餐食、体重、草稿或 Health Connect 数据，因此只证明通道切换、应用内发现／下载、签名校验、系统覆盖安装和启动路径，不宣称数据迁移已通过。
- 食物再次分析的真实 AI 基准与再次分析测试仍因缺少用户授权的私有 AI 配置而被跳过；固定响应和 Mock 不能替代真实模型服从率验证。
