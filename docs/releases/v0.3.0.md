称伴 · ScaleMate 0.3.0 加入应用内更新与正式／预览双通道。

### 本版变化

- 在设置中点击当前版本即可检查更新；发现新版本后，设置入口与当前版本行显示提醒。
- 支持正式版／预览版通道。默认只接收正式版；主动选择预览通道后可接收更频繁的预览版本及更新的正式版。
- 下载可选择 GitHub 官方或五条免费公共代理线路；每条试读 64 KB，显示速度与耗时，帮助选择当时较快的线路。
- 可选自动下载、流量限制、下载进度、取消和重试。安装前校验签名清单、APK 大小、SHA-256、包名、版本和固定发布签名；Android 始终显示系统安装确认。
- 独立开发版、Debug 和测试／原型构建改用橙色 Logo，正式与公开预览保留绿色；正式／预览共用同一 App，不会因升级增加桌面应用。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。此正式版为 versionCode 7，比 0.3.0-preview.1（code 6）更高，可从同签名旧正式版及该预览版覆盖升级。旧版本尚无更新器时，仍需手动下载安装一次；独立饮食开发版的数据不会自动合并，旧 debug 签名包不能直接覆盖，请勿为安装而卸载仍有需要数据的应用。

预览版仍可能不稳定，切回正式版必须有更高版本码，不支持降级。自动检查在应用启动或回到前台时执行，不含应用关闭后的后台定时检查。公共代理可能限流、缓存旧文件或停止服务，少量试读速度不代表完整下载速度。

蓝牙称重不依赖 AI 或 API 密钥。在线饮食识别是估算，使用用户配置的 AI 服务并可能产生外部费用；手动记录、食物库与称重不依赖 AI。饮食与体重分别授权写入 Health Connect，目标应用仍需自行获得读取权限并读取对应数据；写入成功不代表 Google Fit 等已显示。

附件包含 APK 摘要、固定签名信息及签名更新清单，便于复验。本版没有加入健康 AI 对话、主动提醒或 JSON／Prompt 导出。
