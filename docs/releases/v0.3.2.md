称伴 · ScaleMate 0.3.2 修复记录首页自动称重，并优化餐食录入、营养建议与隐私说明。

### 本版变化

- 修复打开记录首页后蓝牙监听被停止、站上秤无法自动接收体重的问题；恢复前台称重接收与原有稳定保存流程。
- 整餐食用建议顶部集中展示总能量、蛋白质、碳水化合物和脂肪，并保留分析耗时与 Token 用量。营养摘要随已确认食物编辑更新，建议采用更柔和的主题配色，引导 AI 结合本人摄入说明营养搭配。
- 餐食详情改为固定高度底部弹层，打开后保持原 Tab，只滚动内容；修正标题点击阴影圆角与底部背景覆盖，支持查看逐项食物、修改、再吃一次及删除确认。
- 记录食物、添加照片、分析核对、手动录入和食物库在同一弹层内完成，保存后关闭并回到原列表。饮食 Tab 保留首页；开始记录时可继续有内容草稿，或明确清空后开始新餐，同餐追加食物不会清空该餐。
- 设置中的隐私说明改为与应用一致的分区卡片，说明本地保存、蓝牙、Health Connect、AI 图片上传与费用、更新代理请求及删除和撤权的影响。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。本版 versionCode 为 12，高于 0.3.2-preview.1（code 11）、0.3.1（code 10）及更早公开版本。正式版与公开预览版共用 `app.scalemate`、绿色图标和固定发布签名，可在保留本地数据的前提下正常覆盖升级；请勿为安装而卸载仍有数据的应用。

正式与预览更新通道均可接收本版正式更新，不支持降级安装。更新检查在应用启动或回到前台时执行，不包含关闭 App 后的后台定时任务，系统安装仍需用户确认。

橙色调试测试版 `app.scalemate.fooddev` 与公开包隔离，数据不会自动合并。旧 debug 签名包不能直接覆盖为公开版。

### 已知限制

- 营养、份量与食用建议是 AI 估算，受图片质量、遮挡和隐藏用油等影响，不代替称量或医学建议。识别速度和 Token 用量取决于配置的外部服务，服务未返回用量时无法提供完整统计。
- 在线饮食识别使用用户配置的 AI 服务，可能产生外部费用；手动饮食记录、食物库与蓝牙称重不依赖 AI。
- 饮食与体重分别授权写入 Health Connect，目标应用还需读取权限，写入成功不代表 Google Fit 等已显示。
- 公共 GitHub 下载代理可能限流、缓存或停止服务；少量试读测速只反映当前网络，不能保证整包下载速度与长期可用性。
