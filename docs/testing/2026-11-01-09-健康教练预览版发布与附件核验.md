## 本版范围与功能验证

健康页开启“今日建议”：基于实际 Health Connect 读取与缓存的近期事实及个人基线，生成短建议，保留独立的健康摘要发送同意。主睡眠与补充睡眠分开展示，累计活动区分当天未完整数据，体重测量不再误标为未完成。限制 Prompt 大小，并用短证据别名校验引用、映射回本地详情。

按用户本轮确认，`HEALTH_COACH_ENABLED=true` 对预览、正式和隔离测试构建均默认开启；旧正式版不会因此改变。`HEALTH_AI_ENABLED=false` 继续关闭原分析、对话、导出和主动提醒。此次只发布预览包。

- 功能阶段在 API 36 模拟器使用经用户授权导出的 Health Connect JSON，调用真实 `workbuddy/deepseek-v4.1-flash`，最终连续两轮成功，约 3.1 秒与 6.7 秒。早期大输入超过限制，精简后本轮样本为 15 个事实、6,412 bytes；长证据 ID 兼容问题也在成功轮次前修复。耗时仅代表本轮样本。
- 本地 296 项 JVM 单测通过，0 失败、0 错误、0 跳过；Lint 无错误、139 条告警；翻译检查和 Debug 构建通过。
- 没有修改饮食识别 Prompt，未重新执行四张饮食 Prompt 基准。
- 私有健康 JSON、API 配置、数据库和私人照片未进入 Git；本轮不进行数据库备份。功能阶段的临时健康 JSON 与仪器测试工具已清理。

## 边界与待办

- 真实 AI 结果来自功能阶段的隔离测试版；此次公开 APK 仅验证附件、升级、导航与未授权空状态，没有重新配置私人 API 或再次导入私人健康数据。
- 公开包模拟器没有已有餐食、草稿或 AI 服务；首次安装时间不变不能替代非空业务数据迁移对比。
- 本轮未安装公开包到用户手机，真机公开包的健康授权、教练结果与非空数据升级仍待用户验证。
- 用户随后反馈检查更新慢：代码每次串行验证最多 20 个历史版本，各自下载清单与签名，且未复用已验证清单；慢线路超时也会叠加。本版未包含检查更新性能优化，后续应独立实现、验收和发布新版本，不替换本 Tag 或附件。
