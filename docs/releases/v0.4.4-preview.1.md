称伴 · ScaleMate 0.4.4-preview.1 改进菜品合并：识别时由 AI 给出合并建议与自然菜名，结果页直接按建议预选项目并预填菜名，不再要求用户手写菜名。

### 本版变化

- AI 识别在判断多项结果属于同一道自然成品菜时，可附带合并建议：合并后的菜名与对应食物项目。独立配菜、饮料和完整菜品不会被错误纳入建议。
- 照片结果页只在存在有效建议时显示“合并为「菜名」”；打开后建议项目已勾选，菜名和份量已预填，用户可以微调后确认。
- 没有合并建议时不再显示通用合并入口，避免让用户从空白开始选择并填写菜名。
- 合并仍只累加已经确认的本人摄入，不按人数二次换算，也不额外调用 AI；缺少某项营养或克数时对应合计保持未知。
- 删除项目、更换照片或完成一次合并后，已失效的合并建议会自动清理；草稿恢复与多建议场景沿用同一套建议数据。

### 已知问题与不稳定风险

- 这是预览版，仅完成固定草稿数据的模拟器界面验证和 JVM 回归；尚未使用 4 张基准样例对真实 AI 跑合并建议回归。不同模型可能不返回建议、给出不合适的合并分组，或菜名语言不符合应用设置。
- 合并只汇总已有识别结果，不会修正营养估算本身的偏差；如果识别营养有误，请在合并前编辑或重新分析。
- 尚未验证小屏、键盘弹出、深色和动态配色下的完整弹窗布局。
- 公开预览版与正式版共用 `app.scalemate` 包名和固定发布签名，不能同时安装；预览版数据不会自动合并到正式版。

### 安装与升级

本版 versionCode 为 30，高于 `0.4.3 / code 29` 及此前全部正式与预览版本。下载 **ScaleMate.apk**，需要 Android 14 或更新版本；继续使用 `app.scalemate`、绿色图标和固定发布签名，请直接覆盖升级，不要卸载已有应用。

预览版以 GitHub prerelease 发布，不会占据 Latest 正式下载入口。需要在应用内主动切换到预览通道才能发现本版；下载并校验后由 Android 显示安装确认，不会静默安装。不支持向更低版本码降级，隔离测试版数据不会自动合并到公开包。

### 隐私与费用

合并建议随正常照片识别一起生成，合并操作本身不调用 AI、不发送新图片或健康数据。识别仍由用户主动发起并发送给所选 AI 服务，外部服务可能收费。健康读取与饮食／体重写入仍需分别授权，目标健康应用还需自行允许读取。检查更新、线路测速和下载不携带餐食、体重、健康数据或 AI 密钥。
