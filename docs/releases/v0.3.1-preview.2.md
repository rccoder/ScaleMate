称伴 · ScaleMate 0.3.1-preview.2 改进了饮食记录结果、草稿续接和更新下载反馈。

### 本版变化

- 图片分析完成后，整餐食用建议、分析耗时和 Token 用量集中显示在结果顶部；建议采用更柔和的卡片样式，并区分格式异常、空正文、输出截断、超时、网络、鉴权和限流问题。空正文或格式不符合约定时最多重试 3 次，界面会显示当前重试次数。
- 记录页和饮食页可直接续接有效草稿；有照片时直接进入照片分析页，有待确认结果时直接进入结果页，不再先进入额外选择页。只有选中图片、填写说明或标签、已有分析结果或已加入食物时才显示“继续未完成的餐食”。
- 保存餐食改为右下角大尺寸圆形按钮，使用深绿背景、白色对号和白环进度；分析完成和首次滑到底部时会轻抖提示，点击后直接返回记录页。
- 设置页在发现新版本时显示小红点。更新页会显示当前下载线路、已下载大小、实时速度和预计剩余时间，并提供下载线路选择。
- 首页历史记录直接按日期展示，饮食与体重统一混排；今日时间线为空、待同步数量为 0 时不再显示对应空模块。

### 已知问题与预览风险

- 预览版更新更频繁、仍可能不稳定；本轮主要验证图片分析、草稿续接、保存按钮和更新下载反馈，真实慢网、大量并发以及部分公共代理的长期稳定性仍需继续观察。
- 公共 GitHub 下载代理可能限流、缓存旧文件或停止服务；应用内少量试读测速只能帮助比较当前网络下的线路，不能代表完整 APK 的下载速度。
- 图片营养数值、份量和整餐建议均为 AI 估算，可能受遮挡、隐藏用油和照片质量影响，不代替称量或医学建议。
- 应用仅在前台启动或回到前台时检查更新，不包含 App 关闭后的后台定时任务。

### 安装与数据

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。正式版和预览版同为 `app.scalemate`，沿用固定发布签名；正常覆盖升级保留本地数据，但不能替代备份。独立饮食开发版的数据不会自动合并，旧 debug 签名包不能直接覆盖，请勿为安装而卸载仍有需要数据的应用。

在线饮食识别使用用户配置的 AI 服务，结果可能产生外部费用；手动饮食记录、食物库与蓝牙称重不依赖 AI。饮食与体重分别授权写入 Health Connect，目标应用仍需自行获得读取权限，写入成功不代表 Google Fit 等已显示。
