# 记录首页自动称重回归与修复

> 2026-10-24。用户报告打开 App 后直接站上秤不能自动称重。已在现有公开预览包复现首页停止扫描，在原橙色测试版覆盖安装修复后验证首页恢复扫描；用户随后实秤确认可正常称重。修复尚未发布到公开通道。

## 原因与影响

`e317a43` 将历史记录直接并入记录首页，删除旧的 `foodRecords` 视图开关时，将原先仅在饮食记录视图暂停监听的条件改为所有 `records` 页面都暂停。App 默认页面正是 `records`，因此启动后蓝牙扫描被停止，无法接收新的秤读数。该改动进入了 `0.3.1-preview.2` 与 `0.3.1`。

`ScaleMateApp.kt` 中页面变化的 `LaunchedEffect` 与即时导航还使用了不同的判断：导航到记录页时短暂允许监听，随后页面副作用又停止扫描。已将两个入口统一调用 `pausesScaleListening`，记录首页允许监听，饮食页面仍暂停，避免称重打断饮食操作。原有权限、前后台限制、稳定判断、自动保存开关及重复测量保护保持原逻辑。

安装前核对原测试包与新 APK 的证书 SHA-256 一致，仅以 `adb install -r` 覆盖已有橙色测试版，不新增应用包、不卸载、不清数据。修复测试包版本字段仍为 `0.3.1 / code 10`，本地工作区构建，不是公开正式版更新；绿色包仍为原预览版。
