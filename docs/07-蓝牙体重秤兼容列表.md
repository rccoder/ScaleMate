# 蓝牙体重秤兼容列表

> 本页区分“协议已实现”“已有真实抓包向量”“模拟器 Mock 流程通过”和“真实硬件已验证”。除特别注明外，新增型号尚未在称伴内完成实秤验收；不能仅凭扫描到设备名或 JVM 测试通过，就宣称对用户完全兼容。

## 范围与产品边界

称伴当前只保存实测体重。即使体脂秤协议中携带脂肪率、阻抗或其他人体成分，当前版本也不会把它们写入称伴记录或 Health Connect。部分连接型协议需要用户档位才能完成握手；当前没有年龄、性别、身高设置页，因此使用固定的中性握手档位（用户号 1、170 cm、30 岁、男性），该档位不代表真实用户资料，也不用于对外展示人体成分。

同一台手机可以保存多台已绑定秤，首页和设备管理页可选择当前称重设备；应用同一时间只监听一台当前设备。设备记录和称重来源分别保存绑定 ID 与型号，切换或移除其他秤不会混淆历史记录。

首批优先覆盖在中国市场较常见、且不需要账号云端密钥的协议路径：小米标准 GATT、云麦 Mini/SE、PICOOC 连接型、荣耀 AH100/CH100、realme RMH2011，并保留现有云麦广播和小众广播型号。华为 Hagrid 系列、小米 S 系列等需要绑定或云端派生密钥的协议不在当前兼容承诺内。

协议实现参考公开协议事实、独立抓包和 JVM 测试向量；openScale 采用 GPL-3.0，称伴未复制其大段实现代码。openScale 的支持列表仅作为型号与协议来源线索，不构成硬件兼容验证。

## 暂不支持或不在首批承诺

| 产品线 | 原因 | 后续条件 |
| --- | --- | --- |
| 华为智能体脂秤 2 Pro（HAG-B19）、华为体脂秤 3 / 3 Pro | Hagrid WSP 系列需要绑定或云端派生密钥，不能只靠本地 MAC 完成 | 明确密钥来源、授权与退出机制后单独验收 |
| 小米/米家 S400、S400 Pro、S800、S200 | S 系列使用绑定或云端密钥，协议和 Mi Scale 2 不同 | 获得可合法使用的本地密钥流程与真实抓包后实现 |
| 荣耀智能体脂秤 CH100S | 与 AH100/CH100 是不同协议，不能误识别到 `AH100` | 独立协议实现和抓包测试 |
| Keep S3 | 协议依赖用户资料或令牌，现有握手模型不足 | 先补齐用户档案与安全的会话令牌 |
| 经典 SPP 型号，例如 iHealth HS3 | Android BLE 传输层不覆盖 Classic SPP，且不是首批主流 BLE 路径 | 单独设计 SPP 传输与权限流程 |
| RyFit、Omron 以及其他区域型号 | openScale 存在支持记录，但中国当前主流度、协议可用性和实机条件不足 | 用户明确要求并通过真实设备抓包后再排期 |

## 验证分层

| 层级 | 已证明 | 未证明 |
| --- | --- | --- |
| JVM 协议测试 | 帧长度、校验、单位换算、最终帧、命令序列和真实抓包向量解析 | Android BLE 栈、设备连接时序、固件差异 |
| 模拟器 Mock | 16 个目录型号的扫描候选、选择设备、确认、移除旧绑定、绑定、首次试称、手动保存模式、再次称重、本地落库界面 | 真实射频、真实广播／GATT 服务、实秤读数 |
| 模拟器多秤 Mock | 两台不同型号绑定共存、设备列表、首页选择器、当前设备持久化、双向切换和称重来源归属 | 多台真实设备并行连接、射频切换、重连时序 |
| 真机实秤 | 云麦 YMBS-M263 已有历史验收 | 其余型号尚未逐台完成连接、读数一致性、重连和长时间稳定性验收 |

2026-10-31 已在 API 36 模拟器用 debug-only Mock 逐一跑通全部 16 个目录型号。每个型号都实际移除上一项绑定，重新扫描候选、核对确认对话框、完成首次试称、选择手动保存、再次称重并核对 SQLite 中的绑定与测量型号；截图和步骤见 [全型号 Mock 交互验收](testing/2026-10-31-05-蓝牙体重秤全型号Mock交互验收.md)。该结果不覆盖真实广播包、GATT 连接、通知时序和固件差异。

另在同一测试版中保留 OKOK VF0，并新增小米体重秤 2，验证两台设备共存、首页选择器切换、偏好持久化，以及两台设备各自的称重记录归属；见 [多秤绑定与切换验收](testing/2026-10-31-06-蓝牙体重秤多秤绑定与切换验收.md)。该测试不表示应用会同时连接两台真实设备。

新增型号至少需要完成：真实设备扫描与 GATT 服务核对、连续三次读数与秤面一致、断线重连、前后台切换、同一手机重新绑定、至少一款目标机型系统日志检查。涉及人体成分或健康写入时还需另做产品、隐私和 Health Connect 验收，不能沿用“体重兼容”结论。
