- 本轮没有重新调用真实外部 AI。真实 DeepSeek 图片识别证据以 [食物识别长推理流回归](2026-11-01-02-食物识别长推理流回归.md) 的同一照片连续 5 次请求，以及用户对预览版的真机确认共同为准。
- 模拟器升级前没有非空餐食、体重、草稿或已绑定体重秤，因此本轮正式版验收覆盖正常覆盖安装、版本与签名一致、启动和设置保留；非空业务数据迁移仍以用户真机业务流程和后续迁移测试为准。
- 正式版没有安装到用户手机；用户确认的是功能代码相同的 `0.4.1-preview.1`，正式 APK 的安装与升级由公开 Release 用户继续完成。
- 本轮没有修改食物识别 Prompt，因此没有重新执行 4 张真实 AI Prompt 基准；固定响应、本地测试和模拟器 Mock 不能替代真实模型质量评测。
