# 称伴开发指南

Kotlin、Jetpack Compose、Material 3，最低 Android 14。先读 [文档索引](00-文档索引.md)，当前行为以代码为准。

## 构建

使用 JDK 17、Android SDK 36，在仓库外配置 SDK 或在未跟踪的 `local.properties` 中设置 `sdk.dir`。

手机调试使用完整称伴的隔离测试版：

```sh
./gradlew -PfoodDev :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest --console=plain
python3 scripts/check_i18n.py
```

`foodDev` 是历史构建参数，包名沿用 `app.scalemate.fooddev`，显示名称为“称伴 · 测试版”，图标为橙色。它覆盖全部称重、饮食、同步功能的调试，不是独立饮食产品或公开预览版。沿用原签名和包名可保留已有测试数据。

不带参数的普通 Debug 是 CI 构建检查产物，与正式版共用包名但签名不同；不要安装到已有正式数据的手机，也不要卸载正式版解决冲突。公开预览／正式均按 [发布指南](03-发布指南.md) 构建固定签名 release。

## 基础实机测试

先按 [安装约定](04-Android%20包安装与测试环境约定.md) 核对设备、APK 身份和既有数据。测试 App 与仪器测试 APK 必须来自同一次、同参数构建。基础隔离测试使用明确的类清单：

```sh
adb -s <serial> install -r app/build/outputs/apk/debug/app-debug.apk
adb -s <serial> install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s <serial> shell am instrument -w \
  -e class app.scalemate.StoreTest,app.scalemate.FoodStoreTest,app.scalemate.AiFormatTest,app.scalemate.AiServicesTest \
  app.scalemate.test/androidx.test.runner.AndroidJUnitRunner
```

`app.scalemate.test` 显示为 ScaleMate Tests，是临时自动化工具，结束后清理；不是另一种产品版本。上述基础类使用隔离数据库或本机模拟服务。不要无条件运行全部测试：附件校验、真实 AI、公网测速和正式包数据保留有各自前提，详见 [测试与验收指南](02-测试与验收指南.md)。

真实界面验收按当前 UI 定位。启动业务 App 可能自动重试待同步记录，不能承诺启动或切换语言绝无健康写入；不要对正式包执行旧的空记录假设或为了截图清数据。旧冒烟和截图自动化脚本已移除。

实际代码在 `app/`；资源与品牌在 `docs/brand/`，截图在 `docs/screenshots/current/` 及对应验收目录。[健康 AI 未来设计](../design/ai-prototype/README.md)使用显式 `prototype` 构建，不进入正常 debug／release；只在明确的设计演示任务中使用。发展过程见 [项目演进](20-项目演进.md)。
