# 称伴开发指南

技术栈：Kotlin、Jetpack Compose、Material 3。最低 Android 14。

## 构建与测试

使用 JDK 17、Android SDK 36，在 `local.properties` 配置 `sdk.dir`：

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest
python3 scripts/check_i18n.py
adb shell am instrument -w app.scalemate.test/androidx.test.runner.AndroidJUnitRunner
```

安装产物位于 `app/build/outputs/apk/debug/app-debug.apk`。手机仪器测试需另行安装 `app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk`，名称为 **ScaleMate Tests**。它只操作隔离测试数据库与语言资源，不写入真实健康数据；日常使用只需称伴，测试包可卸载。

`scripts/smoke_ui.py` 用于干净安装后的首次引导、页面导航与中英文切换验证，其空记录断言不适用于已积累称重记录的手机。

实际应用代码在 `app/`。`design-prototype/` 与 `design/` 保留早期模拟视觉稿。
