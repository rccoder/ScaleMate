称伴 · ScaleMate 0.3.0-preview.1 是应用内更新功能的首个公开预览版。

### 本版变化

- 设置中的当前版本可进入软件更新页，手动检查更新，或在应用启动、回到前台时按间隔检查；有可安装更新时显示红点。
- 支持正式版／预览版通道。正式版默认不接收预览更新，预览通道也能接收更高版本码的正式版。
- 下载可选择 GitHub 官方或五条免费公共代理线路，支持每条 64 KB 的低流量测速、速度比较和手动选线。
- 支持可选自动下载、流量限制、进度、取消与重试；安装前验证签名清单、APK 大小、摘要、包名、版本和固定发布证书。
- 发布增加签名更新清单。普通 Android 安装始终需要系统确认，不会静默安装。

### 已知问题与预览风险

预览版可能存在下载兼容性、系统安装器或网络切换问题，适合愿意反馈问题的用户。公共代理可能限流、缓存旧文件或停止服务；小样本测速不保证完整 APK 下载速度。当前仅在应用启动或回到前台时自动检查，没有应用关闭后的后台定时检查。

从预览版切回正式版需要等待版本码更高的正式版，不支持降级安装。首个公开更新器版本仍需手动下载一次；已经安装本地更新器测试构建的设备可用于验证应用内升级。

### 安装与数据

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。正式版和预览版同为 `app.scalemate`，沿用固定发布签名；正常覆盖升级保留本地数据，不能替代备份。独立饮食开发版的数据不会自动合并，旧 debug 签名包不能直接覆盖，请勿为升级而卸载仍有数据的旧包。

蓝牙称重不需要 AI 密钥。在线饮食识别仍使用用户配置的 AI 服务，结果为估算，外部服务可能收费；手动饮食记录不依赖 AI。饮食与体重分别授权写入 Health Connect，目标健康应用还需自行获得读取权限并完成读取，写入成功不代表 Google Fit 等已显示。
