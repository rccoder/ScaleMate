## 清理与保留范围

- 保留全部 PRD。首版 PRD 明确历史定位，健康 AI PRD 明确未实现，饮食与更新需求对照当前代码；不把需求当上线状态。
- 保留 `docs/brand/` 全部 7 个文件，包括 Logo、SVG 源文件、导出 PNG 和说明；只修正过强文案，不重设计、不修改截图数据。
- 保留 `design/ai-prototype/` 的健康分析、报告、对话、导出、服务配置、提醒与数据来源设计，共 16 张原始截图；保留 `app/src/prototype/` 可点击原型，默认进入健康页，显式 `prototype` 构建，不进入正常 debug／release，也不算第四种产品版本。
- 删除早期 `design-prototype/` 称重视觉稿、旧饮食图集、无引用的旧截图以及健康探测工程。两个旧截图脚本、旧冒烟脚本和累计索引脚本一并删除，不留可误执行的安装入口。
- README 使用的两张真实饮食图原样迁入 `docs/screenshots/current/`；当前对外图仅保留正在引用的六张。更新的真实发布截图迁入 `docs/testing/update-evidence/screenshots/`，保留该轮事实与边界。
- 新增文档索引、项目演进、当前截图说明与历史发布说明入口。旧术语只在历史事实或兼容解释中出现，常规开发无需读取旧图集和逐轮过程。

Git 仍可查看原始历史，入口见 [项目演进](../20-项目演进.md)。已经公开的 Tag、Release 正文与附件没有移动或替换。
