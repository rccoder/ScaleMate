## 实际附件与代理

- 从 GitHub Release 下载全部七个附件；`sha256sum -c SHA256SUMS` 通过。
- `check_release.py --tag v0.3.1 --apk ...` 通过，核对固定签名、唯一签名者、包名、版本名、版本码和非调试属性。
- `check_release.py --tag v0.3.1 --check-remote-code` 通过，正式版本码 10 高于两个通道全部历史发布。
- `update_manifest.py verify` 通过；固定公钥分别验证 `update.json.sig` 与 `releases.json.sig`，两份签名均通过。
- 固定最新下载入口返回 HTTP 200，实际 APK 大小为 23,832,258 字节。
- 实际通过 A 线路 `gh-proxy.com` 完整下载 APK，大小和 SHA-256 与正式附件一致，耗时约 5.0 秒。该结果只代表本次网络。

原始线路结果见 [v0.3.1-routes.json](update-evidence/v0.3.1-routes.json)，完整附件与手机升级状态见 [v0.3.1-verification.json](update-evidence/v0.3.1-verification.json)。
