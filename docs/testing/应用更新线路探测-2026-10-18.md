# 应用更新线路探测（2026-10-18）

本文记录更新 PRD 中 GitHub Release 下载线路的单轮可用性验证。它只代表本次网络与探测时刻，不代表中国大陆所有地区、运营商或未来版本。

## v0.2.0 历史完整下载

### 对象与环境

- Release：`v0.2.0`
- APK：`ScaleMate.apk`
- 预期大小：`23,489,034` 字节
- 预期 SHA-256：`3f1189c158e2b1adcca45722e26fe8c4050b56d8f573080b25de916f9522e645`
- 环境：当前开发者网络；未在中国大陆多省或运营商网络复测
- 工具：`scripts/check_update_sources.py`，`--jobs 2`，`--timeout 240`

## 方法

1. 下载公开的 `SHA256SUMS`，确认只有 `ScaleMate.apk` 一个目标条目。
2. 对 GitHub 官方和五条候选代理完整下载 APK。
3. 校验响应 `Content-Length`、实际文件大小与 SHA-256。
4. 另发 `Range: bytes=0-1023` 请求，确认代理支持 206 分段下载。
5. 检查代理对 Release 网页和 GitHub API 的行为，仅供线路用途判断。

## v0.2.1 完整下载与最终复测

本轮还完整下载了 `v0.2.1/ScaleMate.apk`，六条线路均为 23,489,466 字节，SHA-256 均为：

`68594d1868911664d28b55097d3a4ac036d5ffe3b40ae2ed92e7c900714a9210`

| 线路 | 完整下载 | 耗时 | 20:36 API | 20:36 APK Range |
| --- | --- | ---: | --- | --- |
| GitHub 官方 | 通过 | 7.3 秒 | 200 | 206 |
| `gh-proxy.com` | 通过 | 6.5 秒 | 200 | 206 |
| `ghfast.top` | 通过 | 1974.6 秒 | 403 | 206 |
| `ghproxy.net` | 通过 | 151.7 秒 | 403 | 206 |
| `gh.llkk.cc` | 通过 | 2.9 秒 | 200 | 206 |
| `gh-proxy.org` | 通过 | 3.3 秒 | 200 | 206 |

API 使用应用实际的 `/releases?per_page=100&page=1`，验证 JSON 列表，四个可用端点均返回 4 个 Release；Range 使用 `bytes=0-1023`，均返回 1024 字节。只读取片段不能代替完整下载。`gh.llkk.cc` 在前轮不同请求中失败，本次实际列表接口成功，按本次结果归为 API 可用。

原始结果：[完整下载](update-evidence/v0.2.1-full-download.json) · [最终 API／Range](update-evidence/v0.2.1-api-range.json)。归档去除 GitHub 临时下载重定向的查询参数。

`ghfast.top` 本轮下载超过 32 分钟，不能称为推荐高速线；`ghproxy.net` 超过两分钟。客户端保留两者供手动备用，UI 标注较慢，自动顺序放最后，并设单线总时限，实际可能在完整下载前超时切线。

服务首页另行核对：[gh-proxy.com](https://gh-proxy.com/)、[ghfast.top](https://ghfast.top/)、[ghproxy.net](https://ghproxy.net/)、[gh.llkk.cc](https://gh.llkk.cc/)、[gh-proxy.org](https://gh-proxy.org/)。最后一个首页跳转至第一个，不代表独立服务商。首页介绍不能替代文件实测，也不赋予称伴 SLA。

## 未验证边界

- 六条线路的完整下载是开发机实际网络验证，未覆盖中国大陆多地区、多运营商、IPv6或手机移动网络。
- 现有公开 Release 没有 `update.json`／签名；本轮无法通过真实更新器从它们执行一次完整的新版本发现与升级。真实 APK 的固定签名校验另见本轮验收记录。
- 尚未验证限流、代理缓存过期和长期离线恢复。无需账号访问不等于永久免费或长期可用。

## 复现

```sh
curl -L --fail --show-error \
  -o /tmp/SHA256SUMS \
  https://gh-proxy.com/https://github.com/rccoder/ScaleMate/releases/download/v0.2.0/SHA256SUMS
python3 scripts/check_update_sources.py \
  --tag v0.2.0 \
  --sha256sums /tmp/SHA256SUMS \
  --jobs 2 \
  --timeout 240
```

脚本在任一线路大小或摘要不一致时以非零状态退出，并输出 JSON 报告。

## 应用内低流量测速与本记录的区别

用户可在下载线路弹窗主动发起六线 64 KB Range 试读，总正文约 384 KB，同时最多两线。结果是本机当时的小样本速度，关闭弹窗可停止，不会自动修改选线。该结果不替代本记录的整包 SHA-256 校验，尤其不能把极慢线路的缓存首段速度理解为整包也快。

手机实际执行小样本测速：六条各 65536 字节，整轮约 5 秒；GitHub 1539ms、A 1298ms、B 1912ms、C 3424ms、D 725ms、E 759ms，D 为本轮样本最快。详见 [手机小样本原始记录](update-evidence/android-small-samples.json)。注意 B 的首段试读只需 1.9 秒，而先前整包下载用了 1974.6 秒，正好说明小样本不能保证完整下载持续速度。
