称伴 · ScaleMate 0.4.3-preview.1 让健康教练记住你的目标与安排，并能围绕同一计划连续追问。

### 本版变化

- 健康教练支持设置目标类型、目标值、每周训练日、单次时长、器械和身体限制；确认后的目标与周计划会进入后续建议和追问上下文。
- 健康页新增“问问教练”，可以围绕当前数据、目标和安排连续提问；每次都会带上已确认的近期行动、临时改期和有效记忆。
- AI 提出的个人偏好、限制或临时改期会先显示为待确认候选。只有你确认后才保存或影响安排，误识别的内容可以忽略。
- 记忆页支持查看、手动新增和删除。删除后，后续教练请求不再携带该记忆；临时改期只影响对应日期，长期周计划只有确认后才会变化。
- 行动反馈新增“部分完成”。部分完成不会生成补练任务；继续支持完成、没做到和太难。
- 增强对真实模型常见输出偏差的恢复能力，包括缺失的可空字段、引用别名、未知引用和尾逗号；无法匹配的健康依据会被安全移除，不阻断整次回答。

### 验证结果

- 333 项 JVM 单测通过，0 失败、0 错误、0 跳过；Lint 无错误，翻译、发布校验和 Debug／AndroidTest 构建通过。
- API 36 模拟器完成固定响应闭环，覆盖目标保存、连续追问、候选确认与忽略、记忆删除、临时改期、部分完成和重启持久化。
- 使用真实 DeepSeek 模型完成 5 轮连续追问，单轮约 3.4～5.2 秒，最终无失败；同时验证了改期、记忆候选和“当前数据能支持哪些判断”的边界。

### 已知问题

- 预览版可能不稳定。真实模型质量目前只代表本轮模型和 5 个问题，不代表其他 AI 服务、模型版本或所有表达都稳定。
- 模型可能偶尔没有返回记忆或改期候选，也可能给出不适合你的建议；这些候选始终需要你确认，不会直接修改长期目标或计划。
- 本轮未在真机重新验证 Health Connect 授权、真实今日数据及跨版本业务数据升级；“旧数据在真实供应商上一定完整可用”仍属于未覆盖边界。
- 本轮没有修改饮食识别 Prompt；原健康分析、对话、报告、导出和主动提醒入口仍关闭。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。本版 versionCode 为 26，高于 `0.4.2 / code 25`、`0.4.2-preview.4 / code 24` 及此前全部正式／预览版本。继续使用 `app.scalemate`、绿色图标和固定发布签名，请直接覆盖升级，不要卸载已有应用。

本版为 prerelease，不占 Latest。请在软件更新中选择预览通道；正式通道不会接收预览版。隔离测试版的数据不会自动合并到公开包。

### 隐私与费用

健康教练只在主动提问并同意 `coach-v3` 数据范围后，把已授权的健康事实、目标、周计划、近期行动和有效记忆发送给所选 AI 服务。发送连接或健康类别变化后会重新确认；不会在后台自动发送。

外部 AI 服务可能收费。蓝牙称重、手动饮食记录和本地健康指标不依赖 AI。健康读取与饮食／体重写入仍分别授权，目标健康应用还需自行允许读取。
