称伴 · ScaleMate 0.4.0-preview.4 优化了 AI 食物分析等待期间的进度反馈。

### 本版变化

- 食物图片分析改为读取服务的流式返回。收到首个正文片段后立即显示“AI 已开始返回”，不再只显示笼统的等待状态。
- 等待期间显示首 Token 延迟和持续递增的粗略输出 Token 估算，例如“首 Token 已在 2.1 秒内返回，当前约 130 个输出 Token”。估算只用于进度反馈，完成后的结果卡继续显示服务实际返回的 usage。
- OpenAI 与 Anthropic 的流式正文和用量事件已分别适配。OpenAI 兼容服务若明确不支持 `stream_options`，应用会自动去掉该可选参数后重试，避免仅因用量参数而无法分析。
- 自动重试时会清空上一轮的首 Token 和估算进度；取消、失败或中断不会保存未完成的识别结果。
- 保留上一预览版的 Health Connect 健康读取、今日指标、近期趋势、全量／增量同步、隐私分级授权、再次分析饮食照片和多型号蓝牙秤能力；健康 AI 分析、对话、导出和提醒仍默认关闭。

### 已知问题与预览风险

- 处理中显示的 Token 数是根据正文长度计算的粗略估算，不是供应商分词结果，不能用于计费或额度判断。部分服务只在响应结束时返回 usage，因此估算值与最终实际值可能明显不同。
- 不同 OpenAI／Anthropic 兼容服务的流式格式、缓冲策略和 usage 支持并不一致。部分服务可能直到完成时才一次性返回正文，或完全不返回 Token 用量；实际延迟仍取决于网络、图片大小、模型和供应商。
- 本轮已通过本地回环协议测试与 API 36 模拟器 SSE Mock 验证，但没有调用真实外部 AI 服务。真实供应商的流式兼容性、首 Token 延迟和长时间连接稳定性仍需继续验证。
- 这是公开预览版，仍可能不稳定。图片营养、份量和建议均为 AI 估算，受照片质量、遮挡和隐藏用油影响，不代替称量或医学建议。
- 公共 GitHub 下载代理可能限流、缓存或停止服务；线路测速只反映当前网络，不能保证长期可用性。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。本版 versionCode 为 17，高于 0.4.0-preview.3（code 16）、0.4.0-preview.2（code 15）和 0.3.3（code 13）。正式版与公开预览版共用 `app.scalemate`、绿色图标和固定发布签名，可正常覆盖升级；请勿为安装而卸载仍有数据的应用。

正式通道不接收本预览版；请在「设置 → 当前版本」主动选择预览通道。切回正式版须等待更高版本码，不支持降级安装。更新检查在应用启动或回到前台时执行，不包含关闭 App 后的后台定时任务，系统安装仍需用户确认。

橙色调试测试版 `app.scalemate.fooddev` 与公开包隔离，数据不会自动合并。旧 debug 签名包不能直接覆盖为公开版。

### 隐私与费用

饮食照片识别使用你配置的外部 AI 服务，可能产生费用；手动饮食记录、食物库和蓝牙称重不依赖 AI。照片会先在设备上压缩并移除 EXIF／位置信息，再发送给所选服务。再次分析会发送上次分析结果作为修改基线；切换服务或新增发送数据前请核对对应同意范围。

Health Connect 读取仍只包含你主动选择并在系统中允许的类别。健康 AI 分析、对话、导出和主动提醒在本版关闭，不会把健康摘要发送给 AI 服务。
