## 真机覆盖升级

测试设备为 Xiaomi 24031PN0DC。升级前生产包为 `app.scalemate` / `0.3.1-preview.1` / code 8；没有新建包名、卸载应用或清除数据。

- 应用内主动检查发现 `0.3.1-preview.2`，下载线路为“自动选择”，下载完成后由应用校验证书签名和清单。
- 通过小米系统“称伴正尝试安装应用”的正常来源确认，随后进入系统安装包扫描和覆盖安装；扫描结束、应用自动返回 `/tmp` 中的现有临时截图来自安装后的记录页。本记录只把它标作“安装后记录保留”，不声称截图本身包含系统“安装完成”文案。
- 安装包 `firstInstallTime` 保持 `2026-10-11 22:58:05`，只更新 `lastUpdateTime`，证明不是卸载重装。
- 安装后版本为 `0.3.1-preview.2` / code 9；从设备读取的已安装 APK 与实际 Release 附件均为 23,832,270 字节，SHA-256 都是 `3de9a45620c2bb663e27ea2610dcaf53c9a62a4c032cc848e2dcfcd889f97347`。
- 升级前已有的饮食与体重记录仍在；升级后设置页仍显示 1 个 AI 服务、图片／文本默认模型、已验证的云麦智能体脂秤 3 SE，以及 Health Connect 体重和饮食均已授权。
- 安装后包列表仍只有正式／预览共用的 `app.scalemate` 和橙色调试测试版 `app.scalemate.fooddev`，没有新增测试 App。

## 未覆盖边界

- 安装完成后无线 ADB 断开，未执行独立的 `UpdateUpgradeDataTest` 只读数据库摘要对比；升级前记录与升级后设置是通过真实界面观察到的事实，不等同于逐表摘要验证。
- 本轮未验证取消系统安装后重试、移动数据限制和长时间弱网；公共代理测速只覆盖本次开发网络。
- 应用内更新使用“自动选择”线路，未把实际下载所命中的具体线路单独显示在本轮截图中；A 线路则另外完成了整包独立核验。
