称伴 · ScaleMate 0.4.3 完成健康教练连续闭环，并补齐小米体重秤与体脂秤的广播读取协议。

### 本版变化

- 健康页首屏优先展示“今日行动”，提供完成标准、替代方案和 `试试／完成／部分`、`没做到／太难` 反馈；完成情况会立即更新本周进度。
- 健康教练支持设置目标、每周训练日、单次时长、器械和身体限制，并围绕已确认的目标、计划、近期行动与记忆连续追问；个人偏好、限制和改期先作为候选，只有确认后才保存或影响计划。
- 周复盘展示完成、部分完成、没做到和太难次数，并给出维持、减少次数或缩短动作的下一步；下周计划只有确认后才应用。已保存计划由本地生成每日行动，不要求每天调用 AI 或联网。
- 小米体重秤／2 使用 `0x181D` 广播读取体重，支持 kg、jin、lbs、稳定和离秤标志；扫描、绑定、首次试称、再次称重和本地保存均可使用该路径。
- 小米体脂秤／2 使用 `0x181B` 广播读取体重，不再错误复用体重秤 GATT 路径。兼容列表区分小米体重秤两代与体脂秤两代；体脂秤只保存体重，不读取或展示阻抗、体脂等人体成分。
- `0.4.3` 正式版包含此前 `0.4.3-preview.1` 至 `preview.3` 已验收的目标计划、连续追问、记忆与改期、部分完成、连续行动闭环和小米广播支持。

### 验证与使用限制

此前预览阶段已完成 349 项 JVM 单测、Lint、翻译与构建检查；健康教练连续闭环使用合成 Health Connect 数据和真实模型完成“生成行动、反馈太难、改为 5 分钟、重新生成、完成、重启持久化”验证。小米体重秤／2 与体脂秤／2 已在 API 36 模拟器完成扫描、确认、首次试称、保存和型号归属验证。

健康教练建议由 AI 按已授权且实际可读的数据生成，可能遗漏信息或给出不合适的建议，不能用于诊断或代替专业医疗意见。上游数据缺失、重复或延迟会影响结果；每日行动、反馈、周进度和已保存计划在本地运行，不会在后台自动发送健康摘要。

除云麦智能体脂秤 3 SE 已完成实机称重验证外，小米体重秤／2 和小米体脂秤／2 目前完成协议与模拟器交互验证，真实设备兼容性仍会因固件、BLE 广播、单位设置、离秤时序或连接距离差异而变化。模拟器 Mock 不证明真实射频、重连或低电量行为。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。本版 versionCode 为 29，高于 `0.4.3-preview.3 / code 28`、`0.4.2 / code 25` 及此前全部正式／预览版本。继续使用 `app.scalemate`、绿色图标和固定发布签名，请直接覆盖升级，不要卸载已有应用。

正式通道和预览通道均可接收本版。下载并校验后点击“安装更新”，由 Android 显示安装确认，不会静默安装。不支持向更低版本码降级；隔离测试版的数据不会自动合并到公开包。

### 隐私与费用

健康教练只在你主动规划、追问或请求解释，并同意相应数据范围后，把已授权的健康事实、目标、周计划、近期行动和有效记忆发送给所选 AI 服务；发送连接或健康类别变化后会重新确认。蓝牙称重、手动饮食记录、本地健康指标和本地行动反馈不依赖 AI。

外部 AI 服务可能收费。健康读取与饮食／体重写入仍分别授权，目标健康应用还需自行允许读取。检查更新、线路测速和下载不携带餐食、体重、健康数据或 AI 密钥；继续核验清单签名、APK 摘要、包名、版本及固定发布证书。
