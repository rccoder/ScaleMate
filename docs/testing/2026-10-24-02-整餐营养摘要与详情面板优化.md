# 整餐营养摘要与详情面板优化

> 2026-10-24。用户要求在分析结果的整体建议中展示总能量与蛋白质、碳水、脂肪，并优化建议卡片及点击已保存餐食后的详情弹层。覆盖现有橙色测试版供用户自行验收，随本轮改动提交主分支，尚未公开发布。

## 改动

- 整餐建议顶部增加营养摘要：大号能量，蛋白质／碳水／脂肪三列，保留分析耗时及实际返回的 Token 信息；下面再展示整体评价、当餐建议和下次建议。
- 数字使用当前食物营养合计，不依赖模型是否在建议正文重复数字。分析核对页汇总本批结果，餐食草稿及历史详情汇总当前整餐；缺项保持未知，不补零，也不执行第二次人数分摊。
- Prompt 增加结合最终本人摄入说明主要能量来源与宏量搭配的要求；应用已展示动态总计，建议正文不固化总数，避免用户修改后旧文字与当前数值矛盾。没有个人目标时不武断评判能量高低。
- 建议卡改用现有主题派生的浅绿背景、标题图标、分区留白。实机检查发现 Material 默认容器带浅紫色，最后一轮调整同时让共享食物卡和详情食物卡使用灰绿背景，未引入新的全局主题。
- 原窄 `AlertDialog` 详情改为固定高度、内容可滚动的底部面板，保留标题、时间餐别、关闭入口及底部操作；补充可展开的食物明细与逐项营养、估算依据和已有建议。删除使用独立确认，保留两种删除范围；修改／再吃一次继续沿用草稿冲突保护。用户随后反馈草稿入口和展开期间的交互问题，修正及最终检查见[后续记录](2026-10-24-03-饮食草稿入口与详情交互修复.md)。
