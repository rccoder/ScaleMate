## 未覆盖边界

- 本轮没有调用真实外部 AI 服务。真实供应商的流式首 Token 延迟、长连接稳定性和 usage 差异仍取决于服务实现，不能由本地回环测试或模拟器 SSE Mock 代替。
- 模拟器升级前没有非空餐食、体重或已绑定体重秤，因此本轮只验证正常覆盖安装、版本与签名一致、启动、更新通道和设置保留；非空业务数据迁移仍需在保留真实测试数据的设备上确认。
- 本轮没有验证手机相机、真实 Health Connect 目标应用读取或真实 BLE 体重秤；这些能力不是本版新增改动，也没有因本次发布验证自动获得通过结论。
- 公共 GitHub 下载代理可能限流、缓存或停止服务；单次测速只反映本轮网络环境。
