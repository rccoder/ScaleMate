# 应用更新实现与验收（2026-10-18）

> 本轮实现应用内更新、双通道发布与公共线路选择，并补充低流量线路测速。工作区本地验证，不代表已经发布新版本。当前公开 `v0.2.1` 不含更新器元数据，真实 GitHub 新版本发现至系统覆盖安装仍需在首个更新器版本发布后验收。

## 范围与数据保护

- 同包名 `app.scalemate`、同固定签名；独立 `app.scalemate.fooddev` 保留隔离用途，更新入口关闭。
- 正式／预览通道、前台自动检查、自动下载与流量开关、手动下载、取消、APK 校验、安装权限引导和重试。
- 设置导航及当前版本两处红点，不自动弹更新弹层；升级后旧缓存不再提醒。
- 下载选线独立于 GitHub API 发现；自动失败回退，手动选线不静默切换。
- 手机未卸载、未清数据，未写真实 Health Connect 记录，也未修改已有餐食、体重、草稿或 AI 配置。

## 实机 UI

设备为 Xiaomi 24031PN0DC，1080×2400；通过无线 ADB。当前界面使用本地固定签名 `0.2.1 / code 5` 构建测试，**不是 GitHub 原版同名附件**，不向公开 Release 上传或替换旧附件。

- 页面宽度：原软件更新页叠加外层 24dp 和内层 20dp，改为沿用外层统一边距。在本机更新页与设置页的分组正文均从 x=105 开始，组卡片左边缘约 x=63；更新页卡片与其他页对齐。
- 软件更新页：检查能够结束并显示“当前通道没有可安装的更高版本”，保存检查成功时间，无旧历史清单请求导致的长期转圈。
- 预览版：点击显示不稳定风险弹窗，取消后仍为正式通道；没有下载安装任何预览包。
- 选线：官方、A～E 均显示；B／C 有较慢说明。选择 B 后界面回显 B；手动检查仍正常，因为版本列表使用 API 可用线路。完成后恢复自动线路。
- 返回：更新页可返回设置。临时屏幕超时恢复原值 60000ms；用户使用其他应用期间停止前台操作，用户明确允许后继续。
- 已有真实数据未改动；截图只归档更新界面与弹窗，无私人相册、健康数据列表或密钥。

截图与步骤见 [应用更新界面](../../design/app-update/README.md)。目前没有更高且带签名清单的公开版本，所以“两处红点点亮”和“下载后版本卡片”主要由合成协议／状态回归验证，不能称为已用真实 Release 视觉验收。

## 小流量测速

线路弹窗增加手动测速、停止、测量时间、样本 Tag、逐线耗时／速度及“已测最快”。每条同一 APK 的前 64 KB，最多两线同时，总试读正文约 384 KB，另有连接和缓冲开销。不会自动改变用户线路或校验信任。

JVM 反例覆盖：返回 200 忽略 Range 时最多消耗 64 KB；HTML、短响应和 HTTP 失败不推荐；取消与总时限停止读取；排名忽略失败和不完整样本。手机实际网络执行 `UpdateRouteProbeDeviceTest`（显式传入 `probePublicRoutes=true` 才访问公网），6 条均成功，每条正好 65536 字节，整轮约 5.0 秒：GitHub 1539ms、A 1298ms、B 1912ms、C 3424ms、D 725ms、E 759ms。正文合计 393216 字节；样本最快 D，不改变选线偏好。原始结构化结果见 [手机小样本记录](update-evidence/android-small-samples.json)。

这项隔离测试不需要解锁或打开 Activity。随后用户解锁，补充在正式包本地构建上验收新增弹窗，见 [测速结果截图](../../design/app-update/screenshots/04-route-probe-results.png)：

- 显示 64 KB／总约 384 KB 的成本说明、样本 Tag、时间、逐线速度和耗时，内容与选择按钮可见，无截断。
- 截图这轮为 GitHub 39.1 KB/s／1.6 秒，A 60.8 KB/s／1.1 秒（已测最快），B 暂不可用，C 21.8 KB/s／2.9 秒，D 42.1 KB/s／1.5 秒，E 46.9 KB/s／1.4 秒；与前一轮结果不同，保留失败结果，不以重测覆盖历史证据。
- 结果出来时仍选中“自动”，没有悄悄切线；点击最快 A 后软件更新页回显 A；重新打开弹窗保留本会话结果，重新测速可正常完成。
- 验收停止按钮时，几轮测量均在自动化抓取可点击节点前完成，因此未实际点到“停止”。取消和限读已有 JVM 反例通过，不能把按钮未实操记为通过。
- 结束恢复正式通道、自动选线和 60000ms 屏幕超时；未修改其他设置或记录。

## 首次失败与修正

- 初版更新页内部重复纵向滚动，实机崩溃；去除内层滚动，沿用 App 外层滚动后恢复。
- 初次新增 JSON 解析 JVM 测试失败：Android stub 的 `org.json` 不支持实际运行；测试作用域添加 JSON 运行库后通过。
- 历史 Release 缺元数据导致反复请求 404、长时间检查；改为 API 资产列表先过滤三个必需附件。
- 发布工作流最初 heredoc 缩进错误、keystore 在后续导出公钥前被删除；使用脚本进行历史版本校验，并在元数据步骤单独恢复／清理私钥。
- 历史版本码最初包含当前 Tag，校验会与自身比较；改为排除同 Tag，同时比较正式／预览的其他 Tag。远端只按 Tag 排除，不把另一个版本的相同版本码当作合法。
- 下载取消最初依赖会被替换的 `downloadJob` 字段；改为每次操作绑定自己的协程取消状态，避免旧下载继续写入及与重试竞争。
- 安装授权异常最初丢失“已下载”操作状态；保留待安装文件，并在再次安装前重新验证。
- YAML 验证最初因环境没有 PyYAML 无法执行；仅在仓库外临时安装依赖，解析和 shell 语法检查后通过。
