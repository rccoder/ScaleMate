称伴 · ScaleMate 0.4.3-preview.3 补齐小米体重秤与体脂秤的广播读取协议。

### 本版变化

- 小米体脂秤／2 改为解析 `0x181B` 13 字节广播，从公开协议对应字段读取体重；不再错误复用 `0x181D` 体重秤 GATT 路径。
- 小米体重秤／2 改为解析 `0x181D` 10 字节广播，支持 kg、jin、lbs、稳定和离秤标志。
- 首页扫描、绑定、首次试称、再次称重和本地保存均可使用新的小米广播路径。
- 兼容列表同步区分小米体重秤两代与体脂秤两代；体脂秤只保存体重，不读取或展示阻抗、体脂等人体成分。
- 旧的小米单一 GATT 适配器已移除，避免把体脂秤 2 引导到不适用的标准 Weight Measurement 服务。

### 验证结果

- 349 项 JVM 单测通过，0 失败、0 错误、0 跳过；Lint 无错误，Debug 与 AndroidTest 构建通过。
- 协议测试覆盖 `0x181D` 的 kg／jin／lbs，以及 `0x181B` 的 kg／lbs、稳定、离秤、重复帧、异常长度和超范围体重。
- API 36 模拟器完成小米体重秤 2、小米体脂秤 2 的扫描、确认、首次试称、手动保存、再次称重与 SQLite 型号归属验证。

### 已知问题

- 预览版可能不稳定；本轮没有连接真实小米体脂秤 2，具体固件广播、单位设置和离秤时序仍需实秤确认。
- 模拟器 Mock 只替代蓝牙发现与称重帧，不证明真实射频、连接距离、重连或低电量行为。
- 本轮未执行 Health Connect 写入验证；体脂、阻抗和其他人体成分仍未接入。
- 本轮没有修改饮食识别 Prompt；原健康 AI 分析、旧对话、报告、导出和主动提醒入口仍关闭。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。本版 versionCode 为 28，高于 `0.4.3-preview.2 / code 27`、`0.4.2 / code 25` 及此前全部正式／预览版本。继续使用 `app.scalemate`、绿色图标和固定发布签名，请直接覆盖升级，不要卸载已有应用。

本版为 prerelease，不占 Latest。请在软件更新中选择预览通道；正式通道不会接收预览版。隔离测试版的数据不会自动合并到公开包。

### 隐私与费用

蓝牙称重不依赖 AI，也不需要新增健康数据发送授权。称伴只把读取到的体重保存在本地；写入 Health Connect 仍需单独授权，目标健康应用还需自行允许读取。外部 AI 服务收费与本版的小米广播支持无关。
