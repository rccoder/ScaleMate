称伴 · ScaleMate 0.4.3-preview.2 把健康教练推进到“今日行动 → 反馈 → 周复盘 → 下周确认”的连续闭环。

### 本版变化

- 健康页首屏优先展示一个“今日行动”，包含完成标准、替代方案和 `试试／完成／部分`、`没做到／太难` 两行反馈；全部健康指标后移。
- 完成反馈立即更新本周进度；周复盘展示完成、部分完成、没做到和太难次数，并给出维持、减少次数或缩短动作的下一步。
- 下周计划只有在你确认后才会应用；休息日显示下一次计划，不再把过去行动当作今天必须完成的任务。
- 已保存的周计划由本地按日期生成每日行动，不需要每天调用 AI 或联网；无 AI 服务时仍可查看行动、提交反馈和查看周进度。
- 健康教练首次规划、太难后的调整、主动追问和复盘解释仍可使用已确认的目标、计划、近期行动与记忆作为上下文。

### 验证结果

- 344 项 JVM 单测通过，0 失败、0 错误、0 跳过；Lint 无错误，Debug 与 AndroidTest 构建通过。
- API 36 模拟器完成 6 项交互验证，覆盖今日行动、完成／太难反馈、周复盘、休息日、中英文、深色模式和大字体。
- 使用合成 Health Connect 季度数据和真实模型完成一条完整闭环：生成行动、选择太难、改为 5 分钟、重新生成、完成、重启持久化及失败时保留旧行动。

### 已知问题

- 预览版可能不稳定；真实模型只验证本轮合成健康数据与一种连续闭环，不代表所有供应商、模型版本、网络或真实健康数据都稳定。
- 本轮未在真机重新验证 Health Connect 授权、用户真实健康数据或非空业务数据跨版本升级。
- 月度目标进展、跨月自动进阶、计划版本历史和训练 RPE／组数仍是后续能力。
- 原健康 AI 分析、旧对话、报告、导出和主动提醒入口仍关闭。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。本版 versionCode 为 27，高于 `0.4.3-preview.1 / code 26`、`0.4.2 / code 25` 及此前全部正式／预览版本。继续使用 `app.scalemate`、绿色图标和固定发布签名，请直接覆盖升级，不要卸载已有应用。

本版为 prerelease，不占 Latest。请在软件更新中选择预览通道；正式通道不会接收预览版。隔离测试版的数据不会自动合并到公开包。

### 隐私与费用

健康教练只在你主动规划、追问或请求解释，并同意 `coach-v3` 数据范围后，把已授权的健康事实、目标、周计划、近期行动和有效记忆发送给所选 AI 服务；发送连接或健康类别变化后会重新确认。已保存计划、每日行动、反馈和周进度在本地运行，不会在后台自动发送。

外部 AI 服务可能收费。蓝牙称重、手动饮食记录、本地健康指标和本地行动反馈不依赖 AI。健康读取与饮食／体重写入仍分别授权，目标健康应用还需自行允许读取。
