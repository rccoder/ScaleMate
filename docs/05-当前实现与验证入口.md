# 当前实现与验证入口

> 本页只提供源码定位。已经发布的行为以相应 Tag 的代码为准；历史首次引导与设计方案不作为当前实现依据。发展脉络见 [项目演进](20-项目演进.md)。

| 能力 | 当前源码 | 验证入口 |
| --- | --- | --- |
| 蓝牙称重、稳定判断、去重、首次试称 | `core/`、`ScaleViewModel.kt`、`platform/BleTransport.kt` | JVM 称重／型号／协议测试；实秤验证按任务进行 |
| 本地记录与迁移 | `data/Store.kt`（SQLite v6）、`food/FoodStore.kt` | StoreTest、FoodStoreTest、HealthStoreLocalTest；覆盖升级另做只读对比 |
| 饮食识别与本人摄入 | `food/AiClient.kt`、`AiWire.kt`、`FoodJson.kt`、`FoodViewModel.kt` | 固定响应、协议与存储测试；真实 AI 单独启用 |
| 饮食和体重同步 | `food/NutritionOutput.kt`、`platform/HealthOutput.kt` | 模拟／隔离验证不等于真实 Health Connect 和目标 App 显示 |
| 健康读取、指标与来源 | `health/HealthReader.kt`、`HealthMedicalReader.kt`、`HealthRecordMapper.kt`、`HealthMetrics.kt` | 合成统计、原生类型映射的 Robolectric 测试；真实授权与平台去重待实机 |
| 健康全量／增量与本地缓存 | `health/HealthSync.kt`、`HealthStore.kt`、`HealthViewModel.kt`；`health_records`、`health_sync_state` | HealthSyncLocalTest、HealthStoreLocalTest；显式开启的 HealthSyncDeviceTest 在模拟器验证真实 Health Connect 变更与聚合 |
| 健康报告、对话与导出（功能关闭） | `health/HealthPrompt.kt`、`HealthViewModel.kt`、`HealthExport.kt`、`food/AiStream.kt` | 代码保留；`BuildConfig.HEALTH_AI_ENABLED=false` 时页面入口关闭。恢复前需完成事实引用／数值校验、真实服务和产品验收 |
| 本地规则提醒与健康存储（提醒关闭） | `health/HealthReminderPolicy.kt`、`HealthReminderWorker.kt`、`HealthStore.kt` | 健康快照／迁移测试保留；功能开关关闭时不注册提醒任务。恢复提醒前需完成真实后台与通知验收 |
| 设置、导航、权限 | `ScaleMateApp.kt`、`SettingsUi.kt`、`MainActivity.kt` | 相关真实 UI 路径与失败／取消场景 |
| 应用更新与双通道 | `update/`、发布工作流和 `scripts/` | 更新安全测试、实际附件及手机覆盖升级 |

表中路径相对 `app/src/main/java/app/scalemate/`。本阶段只开放健康数据读取、今日指标、近期趋势、来源和权限管理；健康 AI 分析、对话、报告、导出及主动提醒通过 `BuildConfig.HEALTH_AI_ENABLED` 默认关闭，代码和数据结构保留，后续完成验收后再开启。PRD 中的定时 AI 综合分析和长期偏好记忆仍属后续规划。

健康页先显示已保存的快照；首次授权后读取当前可读历史，随后按类别使用 Health Connect 变更令牌。记录、受影响日期的平台聚合和令牌在同一事务中提交；令牌失效或权限／时区变化按类别重新全量核对。切换已缓存的时间范围使用本地记录，不重复扫描历史。归一化缓存与称伴餐食／体重业务表独立，不从业务表补齐健康指标；内部平台 ID 用于处理删除，不进入公开 JSON。详细契约见 [Health Connect 数据能力与格式](06-Health%20Connect%20数据能力与格式.md)。

构建、测试条件和实际验收分别见 [开发指南](01-开发指南.md)、[测试与验收指南](02-测试与验收指南.md)、[饮食验收](testing/2026-10-18-01-饮食功能实现与验收.md)、[发布验收](testing/2026-10-18-02-应用更新双通道发布与升级验收.md)。Brand 及现用截图保留在 [品牌目录](brand/README.md) 与 [截图说明](screenshots/README.md)。
