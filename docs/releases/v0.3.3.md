称伴 · ScaleMate 0.3.3 优化菜品识别粒度，并支持在照片核对页手动合并一道菜。

### 本版变化

- 优化 AI 分组规则：以成品菜或组合餐为记录单位，减少轻食、沙拉、盖饭等被拆成多种原材料的情况；属于组合餐的水果、分区配料、酱汁和用油计入整菜，独立供应的配菜与饮料仍分别记录。
- 结合用户描述、制作摆放和实际供餐关系判断组合，不因同图、同盘或食材类别一律拆分或合并。同一道菜各部分的分食、剩余和未食用成分分别估算后汇总，避免重复计数。
- 照片结果核对页新增“合并为一道菜”：选择至少两项、填写菜名和本人份量，预览合计营养后合并。合并不额外调用 AI，不再按人数分摊；缺失营养保持未知，仍需确认并保存这一餐。
- 合并后的菜品在保存新餐后按菜名进入食物库，方便整菜复用；已有食物库条目与星标不自动重组或删除。
- 合并保留原项目的估算说明与建议，以及整餐建议、分析耗时和 Token 信息；取消合并不会修改待确认结果。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。本版 versionCode 为 13，高于 0.3.2（code 12）及此前两个通道的公开版本。正式版与公开预览版共用 `app.scalemate`、绿色图标和固定发布签名，可正常覆盖升级；请勿为安装而卸载仍有数据的应用。

正式与预览更新通道均可接收本版正式更新，不支持降级安装。Android 系统安装仍需用户确认。橙色调试测试版 `app.scalemate.fooddev` 与公开包隔离，数据不会自动合并；旧 debug 签名包不能直接覆盖为公开版。

### 已知限制

- 新分组规则只影响重新发起的识别，不改写旧分析、草稿或历史记录。不同模型仍可能误拆或误合；手动合并只累加已有本人营养，不能纠正原识别的营养错误或重复计数，保存前请核对。
- 营养、份量与食用建议是 AI 估算，受照片质量、遮挡和隐藏用油等影响，不代替称量或医学建议。在线识别依赖用户配置的外部 AI 服务，可能产生费用；耗时和 Token 统计取决于服务响应。手动记录、食物库与蓝牙称重不依赖 AI。
- 饮食与体重分别授权写入 Health Connect，目标应用还需读取权限；写入成功不代表 Google Fit 等已显示。
- 公共 GitHub 下载代理可能限流、缓存或停止服务；线路测速只反映当前网络，不能保证长期可用性。
