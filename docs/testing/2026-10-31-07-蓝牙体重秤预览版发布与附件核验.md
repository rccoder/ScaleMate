## 应用内升级

在保持数据的 API 36 Google APIs 模拟器 `emulator-5556` 中，升级前已安装：

```text
applicationId=app.scalemate
versionName=0.4.0-preview.2
versionCode=15
firstInstallTime=2026-10-31 12:09:19
```

应用处于预览通道。主动检查后，应用发现 `0.4.0-preview.3`，展示版本说明和预览风险，使用 GitHub 官方线路下载 24 MB 更新包，再由 Android 系统安装器确认覆盖更新。安装后：

```text
applicationId=app.scalemate
versionName=0.4.0-preview.3
versionCode=16
firstInstallTime=2026-10-31 12:09:19
lastUpdateTime=2026-10-31 18:26:46
```

`firstInstallTime` 未变化，说明没有卸载重装。安装后从模拟器拉取的已安装 APK 为 25,888,616 字节，SHA-256 与 Release 附件一致。应用正常启动，软件更新页显示 `0.4.0-preview.3 · 预览版 / 版本码 16`，预览通道保持选中。

本轮模拟器升级前没有非空餐食、体重或已绑定体重秤，因此只验证了正常覆盖安装、版本与签名一致、启动和设置保留；非空业务数据迁移仍须在保留真实测试数据的手机或后续显式数据保留测试中确认。

## 下载线路

实际附件测速中，GitHub 官方、`gh-proxy.com` 和 `gh-proxy.org` 返回的 APK 大小与 SHA-256 均正确，分别约 4.7、8.0 和 4.2 秒完成。`ghfast.top` 180 秒超时，`ghproxy.net` TLS 握手超时，`gh.llkk.cc` 返回 HTTP 522。失败线路没有被描述为可用，也不保证可用线路长期稳定。完整结果见 [source-report.json](2026-10-31-07-preview3-evidence/source-report.json)。

- 本轮没有验证手机相机、真实 Health Connect 目标应用读取或真实 AI 服务；这些能力不是本版新增改动，也没有因本次发布验证自动获得通过结论。
