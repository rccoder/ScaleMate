# 当前实现与验证入口

> 本页只提供源码定位。已经发布的行为以相应 Tag 的代码为准；历史首次引导与设计方案不作为当前实现依据。发展脉络见 [项目演进](20-项目演进.md)。

| 能力 | 当前源码 | 验证入口 |
| --- | --- | --- |
| 蓝牙称重、稳定判断、去重、首次试称 | `core/`、`ScaleViewModel.kt`、`platform/BleTransport.kt` | JVM 称重／型号／协议测试；实秤验证按任务进行 |
| 本地记录与迁移 | `data/Store.kt`（SQLite v5）、`food/FoodStore.kt` | StoreTest、FoodStoreTest；覆盖升级另做只读对比 |
| 饮食识别与本人摄入 | `food/AiClient.kt`、`AiWire.kt`、`FoodJson.kt`、`FoodViewModel.kt` | 固定响应、协议与存储测试；真实 AI 单独启用 |
| 饮食和体重同步 | `food/NutritionOutput.kt`、`platform/HealthOutput.kt` | 模拟／隔离验证不等于真实 Health Connect 和目标 App 显示 |
| 健康读取、指标与来源 | `health/HealthReader.kt`、`HealthMedicalReader.kt`、`HealthRecordMapper.kt`、`HealthMetrics.kt` | 合成统计、原生类型映射的 Robolectric 测试；真实授权与平台去重待实机 |
| 健康报告、对话与导出 | `health/HealthPrompt.kt`、`HealthViewModel.kt`、`HealthExport.kt`、`food/AiStream.kt` | 事实引用／数值校验、双协议流式解析、导出分片与过期失败回归；真实服务另验 |
| 本地规则提醒与健康存储 | `health/HealthReminderPolicy.kt`、`HealthReminderWorker.kt`、`HealthStore.kt` | 频控、缺失／静默／基线、v4 → v5 保留数据测试；真实后台与通知待实机 |
| 设置、导航、权限 | `ScaleMateApp.kt`、`SettingsUi.kt`、`MainActivity.kt` | 相关真实 UI 路径与失败／取消场景 |
| 应用更新与双通道 | `update/`、发布工作流和 `scripts/` | 更新安全测试、实际附件及手机覆盖升级 |

表中路径相对 `app/src/main/java/app/scalemate/`。健康功能已在工作区接入，尚未发布；本地验证不能替代实机授权、真实 AI 和后台通知验收。PRD 中的定时 AI 综合分析和长期偏好记忆仍属后续规划。

构建、测试条件和实际验收分别见 [开发指南](01-开发指南.md)、[测试与验收指南](02-测试与验收指南.md)、[饮食验收](testing/2026-10-18-01-饮食功能实现与验收.md)、[发布验收](testing/2026-10-18-02-应用更新双通道发布与升级验收.md)。Brand 及现用截图保留在 [品牌目录](brand/README.md) 与 [截图说明](screenshots/README.md)。
