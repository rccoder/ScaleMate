称伴 · ScaleMate 0.4.2-preview.3 开启健康教练“今日建议”预览。

### 本版变化

- 健康页新增“今日建议”，结合 Health Connect 实际读取的睡眠、活动及其他已授权指标，展示近期变化与可执行的日常建议。
- 点击生成后使用你配置的 AI 服务；首次发送健康摘要前单独确认，切换服务或发送类别后重新核对同意范围。
- 建议使用精简的近期事实与基线，限制输入大小并校验引用，减少无关明细和无依据的结论。
- 主睡眠与补充睡眠分开展示，当天步数等累计指标保留尚未完整的提示，体重测量不再误标为未完成。
- 健康教练在当前预览、正式与隔离测试构建中均默认开启，后续转正式时保留入口；原健康对话、分析历史、导出与主动提醒继续关闭。已发布旧正式版不因此改变。

### 验证结果

- 相关改动通过 296 项 JVM 测试，0 失败、0 错误、0 跳过；Lint 无错误。
- 使用用户授权的 Health Connect 数据在 API 36 模拟器调用真实 AI，最终连续两轮成功，耗时约 3.1 秒与 6.7 秒；这是本轮模型与网络的样本，不是固定速度承诺。
- 饮食识别 Prompt 未改动，本版不改变食物图片识别和本人摄入规则。

### 已知问题

- 健康教练仍处于预览阶段，AI 可能遗漏信息或给出不合适的建议，不能用于诊断或代替专业医疗意见。
- 建议依赖已选择、已授权且实际可读的 Health Connect 数据；上游延迟、缺失和重复记录会影响结果，不能从缺失推断为零。
- 需要配置支持文本请求的 AI 服务，耗时、可用性和费用取决于外部服务；不在后台自动调用 AI。
- 与原健康页相比，教练需要额外的此前 21 天个人基线，首次同步可能需要读取更多历史数据。

### 安装与升级

下载 **ScaleMate.apk**，需要 Android 14 或更新版本。versionCode 为 23，高于此前正式版与预览版。与正式版共用 `app.scalemate`、绿色图标和固定发布签名，可覆盖升级并保留本地数据，请勿卸载已有应用。

本版为 GitHub prerelease，不占 Latest；请在应用更新中选择预览通道。安装后不支持向较低版本码降级，测试版数据不会自动合并到公开包。

### 隐私与费用

健康摘要只在你主动生成建议并同意后发送到所选 AI 服务；不发送数据库或原始健康导出文件。健康读取与饮食／体重写入仍分别授权。蓝牙称重和健康页本地指标不依赖 AI；外部 AI 服务费用由所选服务决定。
